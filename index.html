Verbinde deinen ESP32.

Diese Vorschau startet mit Demo-Daten. Für echte Messungen wird eine passende ESP32-Firmware benötigt.

GitHub Pages nutzt HTTPS. Lokale ws://-Verbindungen können vom Browser blockiert werden. Für den direkten Access-Point-Betrieb die UI vom ESP32 über HTTP bereitstellen oder einen erreichbaren WSS-Endpunkt verwenden.

Datenformat für die Firmware
{"sampleRate":20000,"channels":[[0,0.2,0.4],[0,0.1,0.2],[0,0.3,0.6],[0,0.1,0.1]]}

Vier gleich lange Arrays in Volt, mindestens 2 und maximal 32.768 Werte pro Kanal. Ein Frame enthält ein vollständiges Zeitfenster. Trigger und Zeitbasis werden bei Live-Daten lokal dargestellt; die Firmware muss die Abtastung separat steuern.
